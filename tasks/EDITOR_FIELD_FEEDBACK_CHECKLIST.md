# 2026-09-22 实机反馈验收清单

本清单只记录这一轮的复现与验收步骤；长期完成状态仍以 `CURRENT_REQUIREMENTS.md` 为准。每个编号对应一个可独立回退的修复提交。参考图：用户提供的 `465.png`（整页）和 `466.png`（页码跳转示意）。真机检查只有用户在 MovinkPad 上完成后才能标记 `DEVICE_VERIFIED`。

## A. 页面与笔记

- [x] **A01 页码快捷跳转**：长按右下角页码弹出可滚动的页面列表，点选后跳到对应页；整块长按可拖动，位置以画布相对坐标持久化，尺寸变化后保持在可见范围。Android 15 窗口测试覆盖三页跳转与拖动；横竖屏和实机触摸手感仍待用户验收。
- [x] **A02 切换笔记恢复进度**：从标题旁的快捷笔记列表切到 B，再切回 A，分别恢复各自最后一页；图库进入、进程重启、删掉原最后页后均有明确回退。保持各笔记独立记录。根因：快捷列表把目标笔记第一页作为显式内部链接传入，覆盖了恢复记录。Android 15 真实窗口测试在 B 的第 3 页切出并切回，通过。
- [x] **A03 Pages 顶部加页按钮**：页面列表滚到中段或底部时，“+”仍固定在面板顶部，点击继续按当前模板加页；长列表与窄面板不遮挡页面项。固定顶栏与滚动列表分层；Android 15 测试滚到第 8 页后仍可打开加页模板。

## B. 绘画质量与性能

- [ ] **B01 重开后笔迹模糊／像素边界**：对比新画、切页、关开笔记、重启进程的同一区域与缩放倍率；定位是持久化分辨率、tile 重采样、滤镜还是缓存，并修复根因。覆盖旧笔记与新笔刷，核对导出图与画布；不靠全局锐化掩盖问题。
- [ ] **B02 画布缩放卡顿**：采样双指缩放期间主线程、tile 解码／合成、帧耗时和内存；减少重复工作，保证缩放后笔尖对齐、绘画和撤销正常。模拟器与 120 Hz 实机分别验收。
- [ ] **B03 切换笔刷卡顿**：采样打开库、选择笔刷、首次落笔的耗时；缓存必要的笔尖／颗粒准备，避免 UI 同步解码；保持笔刷顺序、预览和画笔参数不变。

## C. 颜色与色板

- [ ] **C01 当前主／副色写入**：色环、混色、色板、近似色及吸管选择颜色后，立即写入当前激活的前景色或背景色；切到另一页签不丢色，绘画取到同一颜色。
- [ ] **C02 色块旁换色**：主／副色交换按钮移至两个色块旁；保留清楚的触摸热区与状态反馈；删去无功能的六点按钮，若有功能则明确标示并保留入口。
- [ ] **C03 色板导入模式**：导入前选择“追加”或“替换”；替换只作用于明确选中的色板并支持取消，失败不清空旧色板；两种模式的颜色数、顺序、命名可核对。

## D. 面板与笔刷控制

- [ ] **D01 标签滑动不误拖**：一个停靠块中合并多个页签，手指横向滚动优先滚动；仅从明确拖动区域长按或达到更高位移阈值才拆出页签。验收从最后一项滚回第一项、多指中断和取消恢复。
- [ ] **D02 笔刷面板窄宽阈值**：缩窄时内容先自适应、分类文字省略；到确实无法使用时才折叠。浮窗和停靠都能调窄、重新加宽并记住尺寸。
- [ ] **D03 笔刷大小／透明度微调**：两条进度条旁分别有小号 ±，大小按有限像素步长、透明度按百分点微调；长按连续微调不越界，当前数值与实际笔迹一致。
- [ ] **D04 笔刷记忆标记**：每支笔刷的大小和透明度各最多四个持久标记；进度条预览中的 + 添加，标记可点选、接近时吸附、再次点选后 − 删除。切笔、重启、笔／涂抹／橡皮状态分别核对；拖动时仍可精确越过标记。
